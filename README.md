## Deskripsi Proyek

Halaman ini menyajikan identitas akademik, riwayat studi dalam bentuk tabel semantik,
ringkasan portofolio/fokus belajar, serta formulir konsultasi yang accessible, dibangun
sepenuhnya dengan **HTML5 semantik** dan **CSS3 modern** (tanpa framework).

## Fitur Utama

- Struktur semantik penuh: `header`, `nav`, `main`, `section`, `aside`, `footer`
- Tabel riwayat studi dengan `caption`, `thead`, `tbody`, `tfoot`, dan atribut `scope`
- Dua jenis list: `ul` (keahlian & tag) dan `ol` (tahapan belajar)
- Formulir konsultasi dengan `fieldset` + `legend`, 8 tipe kontrol input (text, email, tel,
  number, radio, checkbox, select, textarea), label eksplisit, dan validasi native HTML5
- Desain estetik: palet warna 60-30-10, tipografi Sora + Inter, sudut membulat, bayangan
  lembut, tata letak Flexbox & CSS Grid
- Responsif penuh di mobile dan desktop via media query `@media (max-width: 768px)`
