Pada area ini, saya mempelajari cara menyusun halaman web yang semantik secara struktur (HTML5), estetik secara tampilan (CSS3 modern), dan responsif di berbagai perangkat. Praktikum kelas PPW (Pemrograman dan Pengujian Web) menjadi arena utama penerapannya.

Teknologi yang Dipelajari
HTML5 Semantik CSS Custom Properties Flexbox & Grid Bootstrap 5.3.3 Responsive Design Web Accessibility
Capaian di Praktikum

  • Minggu 3: Merefaktor dan mengintegrasikan Bootstrap 5.3.3 dengan custom CSS override.

Version Control & Git
Deskripsi Area Studi

Version control adalah keterampilan esensial dalam pengembangan perangkat lunak modern. Menggunakan Git dan GitHub, saya mengelola perubahan kode, bekerja dalam tim secara paralel lewat branching, dan mempublikasikan proyek secara live di GitHub Pages.

Teknologi & Workflow
Git Init & Clone Commit & Push Branching & Merge GitHub Pages Pull Request
Penerapan di Proyek Ini
  • Repository ini dikelola dengan Git dan dipublikasi di GitHub.
  • Setiap praktikum minggu 2 dan 3 dideploy live via GitHub Pages.
  • Commit history merekam perkembangan dari HTML murni hingga integrasi Bootstrap.
